# Peri Peri Grill — Agadir Bay

A proposal-ready showcase website for **Peri Peri Grill — Agadir Bay**, built as a modern, high-speed, SEO-optimized visual refresh of the restaurant's web presence.

Built with **Astro 5** (Static Site Generation), **Tailwind CSS v4**, **React Islands**, and **Motion for React**. Deploys to Vercel as a fully static output (`dist/`).

## Tech stack

- **Astro 5** (Static Site Generation, SEO optimization, zero-JS default shell)
- **React 19 + TypeScript** (Interactive islands for Header, Hero, and Heat Selector)
- **Tailwind CSS v4** (CSS-first design system & theme tokens)
- **Motion for React** (Tactile entrance and flame physics animations)
- **Schema.org Restaurant JSON-LD** (Rich results, Google Maps & Local SEO integration)
- **@astrojs/sitemap** (Automatic XML sitemap generation)
- **OxLint** (Ultra-fast JavaScript/TypeScript linting)

## Getting started

```bash
npm install     # install dependencies
npm run dev     # start the Astro dev server
```

## Available scripts

```bash
npm run dev            # start local development server (Astro)
npm run build          # typecheck + production build -> dist/
npm run preview        # preview the static production build locally
npm run lint           # run oxlint
npm run media:optimize # optimize raw images to WebP via Sharp
```

## Deployment

This project deploys statically to **Vercel** via Git integration:
- **Pull requests** receive automatic Vercel **Preview** deployments.
- **main** branch deploys to **Production**.
- **GitHub Actions** runs lint and static build validation before merge.
- Fully static output in `dist/` with zero runtime server dependencies.

## SEO & Local Search Features

- **100% Pre-rendered HTML**: Crawlers, Googlebot, and social sharing bots (WhatsApp, Instagram, Facebook, iMessage) immediately receive complete text, headings, and images.
- **Schema.org Structured Data**: Validated `FastFoodRestaurant` JSON-LD with geo-coordinates, operating hours, telephone, ratings, and direct Glovo order action.
- **Open Graph & Twitter Cards**: High-contrast, rich social sharing previews.
- **XML Sitemap & robots.txt**: Autogenerated and linked at `/sitemap-index.xml`.

## Project structure

```text
src/
├── assets/          # restaurant images and visual assets (brand/, restaurant/, dishes/)
├── components/
│   ├── astro/       # Zero-JS static sections (SignatureDishes, Story, Gallery, Reviews, Visit, Footer)
│   ├── layout/      # Header island (mobile drawer, reading-band navigation, sticky bar)
│   ├── sections/    # Hero & HeatSelector interactive islands
│   ├── seo/         # BaseHead meta & Schema.org Restaurant JSON-LD
│   └── ui/          # Reusable UI primitives (Container, Button, Eyebrow, Logo, SkipLink)
├── content/         # Editable restaurant data (typed, decoupled from UI)
├── layouts/         # Root HTML shell (Layout.astro)
├── pages/           # Astro page routes (index.astro)
├── styles/          # Tailwind CSS v4 design tokens and fonts (index.css)
└── types/           # Shared TypeScript types
```
